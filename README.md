# 🎯 Quiz Management System

A Full Stack Quiz Management System developed using "React, Spring Boot,Spring Security, JWT Authentication, Hibernate, and MySQL. The system allows administrators to manage quizzes, questions, students, and results, while providing a secure authentication mechanism.

---

##  Features

### Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Logout

### 📊 Dashboard
- Total Quizzes
- Total Questions
- Total Students
- Total Quiz Attempts

### 📝 Quiz Management
- Add Quiz
- View All Quizzes
- Edit Quiz
- Delete Quiz
- Start Quiz

### ❓ Question Management
- Add Questions
- Edit Questions
- Delete Questions
- View Questions

### 👨‍🎓 Student Management
- Add Student
- Update Student
- Delete Student
- View Students

### 🏆 Result Management
- Automatic Score Calculation
- Store Quiz Results
- View Quiz Results

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/nehadarawade/quiz-management-system.git
```

---

## Backend

```bash
cd Backend
```

Install dependencies

```bash
mvn clean install
```

Run Spring Boot

```bash
mvn spring-boot:run
```

Backend runs on

```
http://localhost:8080
```

---

## Frontend

```bash
cd Frontend
```

Install packages

```bash
npm install
```

Run React

```bash
npm start
```

Frontend runs on

```
http://localhost:3000
```
